# Project Glimmer: A Glitch Revival Concept

> This is the original concept document, preserved as written. It is the long-term vision.
> What is actually being built first, and why that differs, is in
> [`01-scope-reality.md`](01-scope-reality.md).

## Game Overview

Project Glimmer builds upon the creative foundation of Glitch while expanding its core systems and
addressing limitations of the original. Our vision retains the charming, non-violent gameplay and
whimsical world while modernizing the experience for today's players.

## Key Improvements

### 1. Expanded World & Narrative

- **Deeper Giant Lore:** Expand on the eleven giants' backstories and personalities, creating more
  distinct regions with unique aesthetics and gameplay mechanics
- **Player-Influenced Evolution:** The world responds more dynamically to collective player actions
- **Seasonal Events:** Rotating world events tied to an in-game calendar that affects resources,
  quests, and NPC behavior

### 2. Enhanced Gameplay Systems

- **Skill System Overhaul:** Replace linear skill trees with branching specializations that encourage
  diverse player roles
- **Housing & Construction:** More robust building mechanics allowing players to construct persistent
  structures and settlements
- **Creature Interactions:** Expanded relationships with creatures beyond the basic interactions of
  the original

### 3. Social & Community Features

- **Guild/Community Framework:** Formal support for player groups with shared goals and resources
- **Player-Created Quests:** Tools for players to create and share their own adventures
- **Trading Economy:** A more robust player-to-player economy with specialized markets and trading
  posts

### 4. Technical Improvements

- **Mobile Support:** Responsive design for play across devices
- **Modern Client:** Updated rendering engine and UI framework
- **Improved Server Infrastructure:** More scalable backend to support larger player populations

## Development Roadmap

**Phase 1: Foundation (3-6 months)**

- Set up development environment with the Glitch source code
- Update core libraries and dependencies
- Create basic client prototype with essential gameplay

**Phase 2: Core Systems (6-9 months)**

- Implement revised skill and crafting systems
- Build enhanced world generation and persistence
- Develop basic social features

**Phase 3: Expansion (9-12 months)**

- Add new regions, creatures, and items
- Implement housing and construction systems
- Develop player-created content tools

**Phase 4: Polish & Launch (3-6 months)**

- Performance optimization
- User testing and feedback integration
- Soft launch and marketing

## Technical Stack

- **Client:** HTML5, WebGL, modern JavaScript frameworks
- **Server:** Node.js backend with improved database architecture
- **Infrastructure:** Cloud-based deployment with auto-scaling

## Monetization Model

A fair free-to-play model with optional cosmetic purchases and supporter benefits, avoiding
pay-to-win mechanics.

## Community Engagement

- Open development process with regular community updates
- Public test servers for feedback collection
- Documentation and tools to encourage modding and extensions

This concept aims to honor what made Glitch special while creating a more sustainable and expandable
game ecosystem that can grow with its community.
