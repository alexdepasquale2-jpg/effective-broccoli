# Polymath Academy 🚀

An interactive educational platform designed to teach the unified connections between **Natural Languages**, **AI Coding & Agents**, **Systems Automation**, and **Simple Mathematics**.

---

## 🌟 The 4 Interconnected Tracks

1. **Natural & Symbolic Languages** 🌐
   - Syntax, semantics, and compositionality.
   - How human grammar bridges to LLM subword tokenization and high-dimensional vector embeddings.
   - Interactive multilingual speech flashcards (Spanish, Japanese, French).

2. **AI Coding & Autonomous Agents** 🤖
   - The anatomy of system prompts, in-context learning, and Chain of Thought (CoT).
   - ReAct (Reason + Act) loop architecture and tool-calling execution engines.
   - Integrated in-browser JavaScript sandbox runner with live console output and celebratory confetti.

3. **Practical Systems Automation** ⚡
   - Webhooks, cron polling triggers, transformation filters, and AI actions.
   - Interactive visual workflow builder with real-time execution step telemetry and JSON payloads.

4. **Simple Mathematics & Visual Logic** 📐
   - Linear equations ($ax + b = c$), slope-intercept foundations ($y = mx + b \rightarrow \text{AI Neuron: } y = wx + b$).
   - Pythagorean theorem ($a^2 + b^2 = c^2$) with dynamic SVG geometry visualizer.
   - Percentage change, profit/discount margins, and exponential compound growth.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router) + React 19
- **Language**: TypeScript (strict mode)
- **Styling**: Tailwind CSS + Custom Dark Theme
- **UI & Icons**: Lucide React + Canvas Confetti
- **Audio**: Web Speech API for native multilingual pronunciation

---

## 🚀 Getting Started

```bash
# 1. Install dependencies
pnpm install

# 2. Run local development server
pnpm dev

# 3. Build for production
pnpm build
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the platform!
