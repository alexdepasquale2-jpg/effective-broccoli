# Next Beat

A 12-minute writing desk for game developer's block. Diagnose the stall, lock one constraint, and leave with a **beat card** — one playable scene, not a lore bible.

## Why this exists

Writer's block in games is rarely a lack of ideas. It is usually:

- an unbounded possibility space (too many cool ideas, too much world), or
- a story that has not yet been forced to survive contact with a **verb**.

A novel can wait for a beautiful sentence. A game cannot. If the player cannot *do* something under pressure, you do not yet have a scene.

## The Beat Protocol

Four principles:

1. **Play before plot.** A beat is what the player does under pressure, not “what happens.”
2. **Constraint is fuel.** Lock a room, a debt, a liar, a timer, or a forbidden verb. Then write badly.
3. **Ugly, then extract.** Eight bad lines. Then one system, one choice, one exit problem.
4. **One beat is a complete session.** You do not owe the campaign or the ending.

### Diagnose, then pick a desk

| The stall sounds like | Protocol |
| --- | --- |
| I'll start when I know what the game is | **First Pressure** |
| If I finish the history, the story will appear | **Iceberg Cut** |
| The plot is good; the build is a different game | **Verb Tax** |
| Everyone explains the quest, then waits | **Mouth with an Obstacle** |
| I have an opening and a maybe-ending | **Reversal Beat** |
| Go here, fetch that, plus 40 gold | **Three-Beat Spine** |
| They have a job; they do not have a week | **Want / Need / Ask** |
| I cannot write scene one until I know the finale | **Write Backward One Door** |
| The first ten minutes are a manual | **First Verb is the Story** |
| I keep starting a better version instead | **Kill the Menu** |

If you only have four minutes: skip diagnosis and deal a **Forced Hand** (location, pressure, verb, complication, NPC, sensory). Reroll once. Do not add a second room.

### Anti-moves (not this sitting)

Do not add a continent, rename the protagonist, open a new engine, wait for the ending, write a glossary, or polish the first sentence. Those are real jobs. They are also the most popular disguises of fear.

## Run it

```bash
npm install
npm test
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Sessions are stored in the browser (`localStorage`). Export any card as markdown and paste it into a GDD.

## Lineage

MDA; Schell's lenses; BioWare/Obsidian scene craft (want, tactic, obstacle, flag); Emily Short on implication; Oulipo / Oblique Strategies; Peter Elbow's ugly draft. Next Beat does not generate your game. It refuses to let you leave without a scene.
