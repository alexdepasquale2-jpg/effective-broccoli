Project Glimmer

A playable slice of a Glitch revival

Skills

AD walk · Space jump · E or click a trant to harvest

What this is

The vertical slice of a Glitch revival, running single-player in this page. The physics, inventory stacking, skill curve and harvest rules are the same modules the real server runs — only the network round trip is replaced.

What it isn’t

The real build is a Node server on Postgres with authoritative rooms over WebSockets, where other players walk past you and everything persists to a database. That needs hosting; this page needs none.

Where the world comes from

Art, music and the complete server-side game code of Glitch were released into the public domain (CC0) by Tiny Speck. The Glitch name and logo were not, and are not used here.
